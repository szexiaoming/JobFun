产品原则

找不到证据，就明确说出来。

真实 JobFun 项目包含 FastAPI、Next.js、异步任务及可选 LangChain 差距解释。此公开页面是独立的合成数据演示，展示交互和产品思路；它没有连接生产数据库，也不会处理朋友的真实简历。
