## 2. CLI 接口

### 2.1 主分析命令

```bash
# 完整分析
python run_agent.py \
  --resume data/resumes/sample_resume.txt \
  --jd data/jobs/ai_agent_jd.txt \
  --github-project data/github_projects/project_agent_eval.md \
  --target-role "AI Agent Developer" \
  --target-city "北京" \
  --salary-monthly 18000 \
  --salary-months 13 \
  --output-format both \
  --mock

# 参数说明
--resume          简历文件路径（.txt/.md）
--jd              岗位 JD 文件路径（.txt/.md）
--github-project  GitHub 项目文件（.md），可多次指定
--github-dir      GitHub 项目目录（批量导入）
--target-role     目标岗位名称
--target-city     目标城市（可选）
--salary-monthly  期望月薪（可选）
--salary-months   年薪月数（可选，默认 13）
--output-format   输出格式：json / markdown / both（默认 both）
--output-dir      输出目录（默认 outputs/agent_reports/）
--mock            使用 Mock LLM 客户端（不调用真实 API）
--verbose         详细输出模式
```

### 2.2 输出文件

```
outputs/agent_reports/
├── career_analysis_20260529_103015.json    # 完整 JSON 结果
└── career_analysis_20260529_103015.md      # Markdown 报告
```

### 2.3 RAG 查询命令

```bash
# 独立 RAG 查询
python run_agent.py \
  --rag-query "如何包装 GitHub 项目用于 AI Agent 岗位求职？" \
  --rag-top-k 5 \
  --rag-filter doc_type=github_project_rules
```

### 2.4 薪资计算命令

```bash
# 独立薪资计算
python run_agent.py \
  --salary-only \
  --salary-monthly 18000 \
  --salary-months 14 \
  --probation-salary 16200 \
  --probation-months 6 \
  --fund-base 7200 \
  --fund-rate 0.05
```

### 2.5 测评命令

```bash
# 运行 AgentEval
python run_eval.py \
  --case-file cases/career_agent_cases.json \
  --mock \
  --output-dir outputs/eval_reports/

# 运行特定类别
python run_eval.py \
  --case-file cases/career_agent_cases.json \
  --category safety_honesty \
  --mock
```

## 3. RESTful API

### 3.1 通用约定

- **Base URL**：`http://127.0.0.1:8000`
- **Content-Type**：`application/json`
- **编码**：UTF-8
- **错误响应格式**：
  ```json
  {
    "error": {
      "code": "INVALID_INPUT",
      "message": "简历文本不能为空",
      "detail": {}
    }
  }
  ```

### 3.2 错误码

| HTTP 状态码 | 错误码 | 说明 |
|-------------|--------|------|
| 400 | INVALID_INPUT | 输入参数不合法 |
| 400 | SAFETY_VIOLATION | 请求违反安全策略 |
| 404 | NOT_FOUND | 资源不存在 |
| 422 | VALIDATION_ERROR | Pydantic 验证失败 |
| 429 | RATE_LIMITED | 请求频率过高 |
| 500 | INTERNAL_ERROR | 服务器内部错误 |
| 503 | LLM_UNAVAILABLE | LLM 服务不可用 |

class LLMClient(ABC):
    @abstractmethod
    def chat(
        self,
        messages: list[dict],
        system_prompt: str | None = None,
        temperature: float = 0.7,
        max_tokens: int = 4096,
    ) -> str: ...

    @abstractmethod
    def chat_json(
        self,
        messages: list[dict],

    ) -> dict: ...

class LLMClientFactory:

## 5. 数据模型（Pydantic Schemas）

所有数据模型定义在 `src/agent/schemas.py`，使用 Pydantic v2 进行验证。

关键 schema 示例：

```python
from pydantic import BaseModel, Field
from typing import Optional, List

class GitHubProjectInput(BaseModel):
    project_name: str = Field(..., min_length=1)
    readme_text: str = Field(..., min_length=1)
    repo_structure: Optional[str] = None
    tech_stack: List[str] = Field(default_factory=list)

class SalaryInfo(BaseModel):
    monthly_salary: float = Field(..., gt=0)
    salary_months: int = Field(default=13, ge=12, le=18)
    probation_salary: Optional[float] = None
    probation_months: int = Field(default=3, ge=0, le=12)
    fund_base: Optional[float] = None
    fund_rate: float = Field(default=0.05, ge=0.05, le=0.12)

class AgentInput(BaseModel):
    resume_text: str = Field(..., min_length=10)
    job_description: str = Field(..., min_length=10)
    github_projects: List[GitHubProjectInput] = Field(..., min_length=1)
    target_role: str = Field(..., min_length=1)
    target_city: Optional[str] = None
    salary_info: Optional[SalaryInfo] = None
```
